# Sample Enterprise Module This is a sample enterprise module created to test your Odoo Enterprise setup. ## Features - Demonstrates enterprise addon loading - Shows that enterprise addons path is correctly configured - Provides a simple menu item for testing ## Installation 1. This module should be automatically detected when you start Odoo 2. Go to Apps menu in Odoo 3. Update the Apps List 4. Search for "Sample Enterprise" 5. Install the module ## Usage After installation, you should see a "Sample Enterprise" menu item in the main menu. ## Verification If you can see and install this module, it means your Odoo Enterprise setup is working correctly and enterprise addons are properly loaded.
